# 智能合同审查 Agent（基于 Dify 工作流）

> 🚧 项目状态：核心工作流已搭建，并于 2026-10-22 完成首轮实测（结果见下方「评测」一节）；文件上传解析、提示词校准等迭代进行中。

个人项目：把 10 年企业法务的合同审查经验，拆解成 AI 可执行的条款规则、风险标签与评测标准，用 Dify 工作流实现合同风险的自动识别、分级与修改建议生成。

## 做什么、解决什么问题

企业合同审查中常见三类问题：风险点易遗漏、审查标准不统一、修改建议缺乏依据。
本项目把法务专家的审查经验拆解为：

- **条款结构化抽取**：合同主体、金额、期限、付款、违约、担保、解除等关键信息
- **风险标签体系**：主体 / 付款 / 违约 / 担保 / 解除等维度分类
- **风险分级与路由**：高 / 中 / 低三级；低风险自动生成审查意见，高风险与依据不确定的条款转人工复核，避免模型在风险边界不清时直接给结论

## 工作流设计

```
合同文本 → 条款切分与关键信息抽取 → 风险识别（条款定位—风险判断—法规依据—修改建议）
→ 风险分级 → 低风险自动出审查意见 / 高风险转人工复核 → 结构化审查报告
```

提示词框架见 `prompts/风险提取节点_提示词模板.md`（可直接粘贴进 Dify Workflow 的 LLM 节点 System Prompt）。其中审核维度（准确 / 逻辑 / 规范 / 简约 / 流畅 / 工整）、问题分类与风险分级口径，参考 wulilaw-contract-review（v1.5）《审核方法手册》，并结合融资租赁等交易场景适配。

## 评测：自建测试集（最小闭环）

| 文件                                         | 说明                                                         |
| -------------------------------------------- | ------------------------------------------------------------ |
| `test-data/虚构测试合同_设备融资租赁合同.md` | 虚构设备融资租赁合同，**预埋 7 处典型风险点**（第 8 条为正常条款，专门检验误报） |
| `test-data/虚构测试合同_预埋风险点答案.md`   | 标准答案 + 评分标准：找出 6–7 处为可用，4–5 处需调优，3 处以下提示词大改；第 8 条误报单独记录 |

评测方法：先让助手审查测试合同、记录找出的风险点，再对照答案打分（召回几个、等级判断准不准、有无误报）。**首轮实测结果（2026-10-22，模型 gpt-5，提示词 v2，审查立场：乙方/承租人）：预埋 7 处风险全部召回（7/7）；风险等级 6 处与标准答案一致，1 处偏高（保证金：标准为中、判为高）；第 8 条正常对照条款出现 1 次误报（性质为归因错位——实为缺失验收机制的问题，模型已另行单列缺失项）；另有 5 条额外有效发现（交付与验收、租金支付安排、发票与税费、权属瑕疵担保四项缺失条款，以及各期租金合计与总额的 12 元尾差勾稽）。结论：达到预设“可用”标准，校准项见路线图。**

> ⚠️ 测试合同中所有公司名称、人物、金额均为虚构，仅用于功能测试，不得作为真实交易依据。
