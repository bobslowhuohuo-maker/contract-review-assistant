# 合同审查助手（Contract Review Assistant）

基于 Dify 搭建的合同风险审查助手｜10 年法务经验 × AI 产品实践

🚧 状态：搭建中（个人练习项目）

## 这是什么

一个基于 Dify 搭建的合同审查小工具：上传合同后，自动标出常见风险条款并给出修改建议。
作者有 10 年法务/风控从业经验，正在转型 AI 产品，本项目是把法律实务经验转化为 AI 产品实践的练习。

## 规划功能

- 上传合同文档并解析
- 风险条款识别：单方调价、过高违约金、单方解除、维修/责任转嫁、保证金退还等
- 每条风险给出说明与参考改写

## 方法

- Dify 工作流编排 + 风险提取提示词
- 评测：使用预埋风险点的虚构测试合同，并预设评分标准验证识别效果

## 说明

测试合同均为虚构文本，不含任何真实客户信息。
